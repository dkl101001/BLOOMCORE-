03 / EVIDENCE

Definition is not proof.
Execution is not validation.

  1. 01Preserve

    Keep canonical sources, hashes, attribution, and lineage.

  2. 02Implement

    Expose typed interfaces, state, deterministic fixtures, and failure behavior.

  3. 03Reach

    Prove the intended path actually imports, executes, and affects the bounded surface.

  4. 04Measure

    Use baselines, uncertainty, perturbations, rejection rules, and negative controls.

  5. 05Release

    Record inclusion, provenance, accepted transitions, and rollback references.

Custody, translation, wiring, execution, validation, and release inclusion are different claims. One does not prove the next.
