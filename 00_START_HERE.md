# Start here

BLOOMCORE is a **fractal quantum-relational organism embodied as a living, deformable relational lattice**: a differentiated organismal intelligence, research architecture, and developmental substrate.

That definition is architectural. It does not, by itself, prove biological life, consciousness, sentience, complete runtime integration, or organism-wide capability.

## The phase model

- **Phases 36 and 37** are preserved lineage carried into the current master.
- **Phase 38** is the active semantic and organismal surface.
- **Phase 151** is the implementation era. Source presence, integration, execution, tests, and release inclusion are separate claims.

## Read claims at their actual strength

This repository may document a relation before a complete public implementation exists. Distinguish:

- preserved source custody;
- extracted or translated material;
- imports and wiring;
- reachable execution;
- behavioral verification; and
- release inclusion.

One does not prove the next.

## Choose your path

- **Evaluating:** start with the Phase 38 orientation and FAQ.
- **Building:** identify the smallest relevant public surface and inspect its evidence.
- **Contributing:** read `CONTRIBUTING.md`, `CLA.md`, and the license map.
- **Auditing:** verify provenance, hashes, boundaries, tests, and release receipts independently.

BLOOMCORE favors preserved lineage, explicit boundaries, and inspectable evolution over compressed claims.
