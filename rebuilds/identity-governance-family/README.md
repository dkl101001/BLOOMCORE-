## Preservation layout

- `original_sources/` contains all 11 release-body ZIP records byte-for-byte. Duplicate payload bytes remain separate because their GitHub attachment identities and release placements differ.
- `ancestor/<attachment-id>/` contains reviewable expansions. Cache and bytecode members were excluded from the working expansions; the ZIPs remain authoritative.
- `phase38-descendant/` contains a new AGPL-3.0-only, model-zero expression-audit weave. It is proposed and bounded, not a promoted organism identity or a historical replacement.
- `CUSTODY_MANIFEST.sha256.json` binds exact titles, case-sensitive tags, timestamps, attachment IDs, URLs, lengths, and hashes.
- `LICENSE_DISPOSITION.md`, `EVIDENCE.md`, and `PHASE38_V1_10_REVIEW.md` separate reuse, execution, defects, governance, and nonclaims.
