\section{Conclusion}
As agentic systems increasingly operate over long horizons, adapt across tasks, and interact with complex environments, evaluation practices must extend beyond outcome-based performance metrics. This work introduces reasoning security as a complementary evaluation dimension that focuses on the post hoc reconstructability and attribution of agent decision processes rather than behavioral quality or control.

We presented the Reasoning Security Score (\RSS), a diagnostic framework that measures structural properties of observable reasoning traces using minimal, architecture-agnostic instrumentation. By decomposing reasoning security into traceability, lineage integrity, adaptation visibility, attribution fidelity, and counterfactual stability, \RSS\ enables systematic analysis of agent behavior across heterogeneous benchmarks without modifying training or inference procedures. We hope this framework supports more transparent, comparable, and interpretable evaluation of agentic systems as the field continues to evolve.
